Neon Coast Cover Studio — a zero-dependency Canvas 2D cover-art maker for GTA 6. Six multi-panel layouts (split duo, trio band, quad grid, hero + strip, diagonal slash, framed poster), five colour grades (Neon Coast, Golden Hour, Midnight, Vice Heat, Mono Ink), a headline kicker ladder with an editable headline, sub-line, badge and price strip, four bundled sample photos (or your own upload), a deterministic Surprise me, and exports at 1080×1080, 1080×1350 and 1920×1080.

## Run it

```sh
node serve.ts
```

Serves `app/` at http://localhost:8080. To write the entry dossier: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
